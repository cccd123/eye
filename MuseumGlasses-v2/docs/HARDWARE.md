# 硬件识别：你手上这块「纸板眼镜」是什么

> 根据 3 张照片判断。标了「推测」的地方需要你用 `glasses/probe_glasses.bat` 或万用表确认。

## 1. 一句话结论

这是**从一副量产 AI 拍照眼镜里拆出来的主板**，被导师/学长飞线固定在纸板上方便调试。
核心是**全志（Allwinner）V821** 芯片，跑 **Tina Linux**（全志基于 OpenWrt 的嵌入式 Linux）。

它**不能在本地跑 CLIP / Qwen**（芯片内存只有 64MB），所以正确的架构是：

```
 眼镜(V821)  ──Wi-Fi──▶  你的电脑(FastAPI + CLIP + RAG + Qwen3 + TTS)  ◀──Wi-Fi──  手机APP
 拍照/录音/放音              所有 AI 计算                                     设置人设/看文字/备用拍照
```

眼镜和手机都通过同一个 Wi-Fi（或手机热点）连电脑。这正是仓库里新写的代码走的路线。

## 2. 照片里每个部件

| 位置（第1张图） | 是什么 | 把握 |
|---|---|---|
| 中间细长黑色板，芯片印 **V821** + 全志 logo | **主控板**。全志 V821：RISC-V 双核（1.2GHz 主核 + 600MHz 小核），**芯片内封 64MB 内存**，**自带 2.4GHz Wi-Fi**（不含蓝牙），MIPI 摄像头接口，1 路麦克风输入 + 1 路音频输出，USB2.0 | 高 |
| 主板下方软排线末端的小镜头 | **摄像头模组**（MIPI CSI）。V821 的 AI 眼镜方案一般配 500~800 万像素 sensor，具体型号看 probe 结果里的 dmesg | 高 |
| 排线上的白字 `AT2549` | 排线/模组厂的料号，不影响使用 | — |
| 胶带「调试USB/烧录」 | 主板的 **USB 口飞线**：用来 **adb 调试 + 刷固件**。电脑连这里 | 高（你们自己写的标签） |
| 顶部胶带「…power / 按键」+ 白色测试钩 | **电源键/功能键**的两根飞线，测试钩夹上去 = 按下按键 | 中 |
| 方形黄色小元件（装在一小段黑色软板末端） | 推测是**白光 LED**（补光灯或「正在拍摄」指示灯——白光 LED 表面就是黄色荧光粉）。也可能是按键，按一下就知道 | 推测 |
| 带橙色圆环+方形铜皮的小板 | 推测是**镜腿触摸板**（铜皮 = 触摸电极，橙圈 = 固定螺丝孔）。量产眼镜常用「触摸镜腿」代替实体按键 | 推测 |
| 左侧一束彩色细线（红/黑/黄/紫/白/棕…）标「GND…」 | 推测是**喇叭 + 麦克风 + 电池**的飞线（原来走在两条镜腿里的线）。眼镜的喇叭/麦克风本体应该在这束线的另一端（第2张图背面） | 推测 |
| 左下胶带「V+ / BAT-」 | **电池接线**：V+ = 正极，BAT- = 负极 | 高 |
| 第3张图的银色电池 | **3.7V 锂聚合物电池**，型号 102050（10×20×50mm），约 **1000mAh**，带保护板（黄色胶带下面那块小电路板）。红线 = 正，黑线 = 负 | 高 |

## 3. 关于电池的安全提醒

- 电池红线接 **V+**，黑线接 **BAT-**，**千万别接反**（接反可能直接烧主板）。
- 不要用 USB 口以外的东西给电池充电；电池鼓包/发烫立刻断开。
- 纸板 + 胶带 + 裸线 + 锂电池：调试时别离人，别压在书本下面。

## 4. 下一步：让电脑「进入」眼镜

**第一步（10 分钟）：** 双击 `glasses/probe_glasses.bat`，生成 `probe_result.txt` 发给我。它只读不写，会告诉我们：
摄像头叫什么、录音放音用哪个声卡、按键是哪个 `/dev/input/eventX`、有没有 `curl`、Wi-Fi 怎么连。

可能出现三种情况：

1. **adb 能连上** → 最好的情况。我根据结果把 `glasses_client.sh` 顶部的配置填好，`adb push` 进去就能跑。
2. **adb 连不上，但有串口**（板子上通常有 TX/RX/GND 三个焊盘，波特率 115200）→ 需要一个 **USB 转 TTL 串口模块**（CH340，十块钱）登录 shell。
3. **固件是加密的量产固件，进不去** → 需要导师那边要 **Tina Linux SDK** 重新编译固件（勾选 adb、curl、alsa-utils），用全志 **PhoenixSuit** 工具通过「调试USB/烧录」口刷进去。这一步一定先问导师，刷错可能变砖。

**第二步：** 让眼镜连上 Wi-Fi，和电脑在同一网段（手机开热点，电脑和眼镜都连上最简单）。

**第三步：** `glasses_client.sh` 跑起来 → 短按拍照讲解、长按语音追问。

## 5. 在板子能用之前

用 `glasses/glasses_sim.py` 在电脑上「假装是眼镜」，协议和真眼镜完全一样。等板子通了，服务器和 APP 一行都不用改。
